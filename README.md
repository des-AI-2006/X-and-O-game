# Tic Tac Toe Game 🎮

A beautifully designed, modern, and fully responsive Tic Tac Toe (X and O) game built with pure HTML5, CSS3, and Vanilla JavaScript. Features interactive animations, customizable player marks, and challenging single-player AI modes.

### 🌐 Live Demo
**Play the game here:** [https://rock-paper-scissors-gamma-lovat.vercel.app/](https://rock-paper-scissors-gamma-lovat.vercel.app/)

---

## ✨ Features

- **Two Game Modes**:
  - **2 Player (vs Friend)**: Play locally with a friend on the same screen.
  - **vs Computer**: Test your tactical skills against an AI opponent.
- **Smart AI Opponent**:
  - **Normal Mode**: The computer makes random moves. Great for a casual game!
  - **Hard Mode**: The computer uses strategic logic to block your winning moves and actively secure its own victories.
- **Customizable Gameplay**: Choose whether you want to play as **Player X** or **Player O**.
- **Modern UI/UX**:
  - Fully responsive layout designed for mobile, tablet, and desktop viewports.
  - Smooth glassmorphism styling, interactive hover animations, and neon glow accents.
  - Disabled global text-selection to provide a polished, native app-like experience.
  - Dynamic full-screen Victory and Draw overlays with instant restart controls.
- **Zero Dependencies**: Pure client-side JavaScript with no build steps or bundlers required.

## 📥 Getting Started & Installation

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/des-AI-2006/X-and-O-game.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd X-and-O-game
   ```
3. **Launch the game:**
   - Simply double-click `index.html` to open it in your default web browser, or
   - Use the VS Code **Live Server** extension for real-time live reload.

---

## 🚀 How to Play

1. Open `index.html` in your browser (or visit the live demo link).
2. Choose your preferred game mode from the home screen: **2 Player** or **vs Computer**.
3. If playing vs Computer, select your difficulty level (**Normal** or **Hard**) and choose your symbol (**X** or **O**).
4. Take turns clicking on the 3x3 grid to place your mark.
5. Get 3 marks in a row (horizontally, vertically, or diagonally) to achieve victory!
6. If all 9 squares are filled without 3-in-a-row, the match ends in a draw.
